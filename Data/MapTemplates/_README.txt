Map Maker templates / patterns
Put your own PNG / BMP / JPG images here (sub folders work too).

Sketch_*.png    : sketch for the generator (transparent = generator decides)
Heightmap_*.png : grey scale height map (dark = sea, bright = mountains)
Map_*.png       : complete map in the colours of Data/System/Terrain.xml
Stamp_*.png     : small patterns for the stamp tool of the editor (transparent = not painted)
